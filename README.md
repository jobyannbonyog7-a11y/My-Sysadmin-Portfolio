# System Administrator Career Portfolio

A modern, interactive, neon-fiery themed web portfolio introducing the System Administrator profession.

## Features

- **Responsive Design** – Works on desktop, tablet, and mobile
- **Dark / Light Mode** toggle
- **English ↔ Tagalog** language switcher
- **Animated Loader** with fire + smoke + neon effects
- **Particle Network** background
- **Interactive Tool Cards** – click for detailed modal + particle burst
- **Terminal Playground** – try real-feeling SysAdmin commands
- **Draggable Student ID** – animated ID badge with keyboard and pointer controls
- **Surprise Effects** on developer name & photo (fireworks + letter pop + fire ring)
- **Smooth scroll navigation**
- **Official tool links** (Windows Server, Ubuntu, PowerShell, SSH, VirtualBox, Docker, Ansible, Nagios)

## Project Structure

```
sysadmin-portfolio/
├── index.html          # Main page
├── css/
│   └── styles.css      # All styles + animations
├── js/
│   └── script.js       # Interactivity, i18n, terminal, particles
├── assets/             # (optional images)
└── README.md
```

## How to Run

1. Extract the ZIP
2. Open `index.html` in any modern browser (Chrome, Firefox, Edge, Safari)
3. No build step or server required – pure HTML/CSS/JS
